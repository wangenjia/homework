# 一箭又一箭

基于 Flask + HTML 实现的方向箭头消除小游戏。

## 游戏简介

点击箭头：若前方路径无阻挡，箭头飞出棋盘并消失。

点击被阻挡的箭头：无法消除，并消耗 1 次失误机会。

界面顶部显示当前关卡、剩余箭头数、剩余失误次数。

## 开发环境

- Python 3.8+
- Flask 2.x
- 浏览器

## 安装和运行方法

1. 安装依赖：

   pip install flask

2. 启动游戏：

   python game1.py

3. 打开浏览器访问：

   http://127.0.0.1:5000

## 游戏操作说明

- 点击箭头：若前方路径无阻挡，箭头飞出棋盘并消失。
- 点击被阻挡的箭头：无法消除，并消耗 1 次失误机会。
- 界面顶部显示当前关卡、剩余箭头数、剩余失误次数。
- 点击“重新开始”按钮可让当前关卡恢复初始状态。
